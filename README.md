# Ali Ahmed - Unity Developer Portfolio

This is a simple three-page portfolio website created for the Web Technologies assignment.

Pages:
- index.html - Home page using inline CSS.
- information.html - Projects page using embedded CSS.
- registration.html - Project inquiry form using external CSS.
- css/style.css - External stylesheet.

CSS is used to control the appearance of HTML pages. It provides colors, spacing, fonts, borders, and layout.

Example:
body { background: #eeeeee; }

The selector is body, the property is background, and the value is #eeeeee.

Inline CSS is written inside an HTML element. Embedded CSS is written inside a style element. External CSS is written in a separate CSS file.

CSS1 introduced basic styling features. CSS2/2.1 added more advanced selectors and layout features. Modern CSS is modular and includes technologies such as Flexbox and Grid.

Browser support is important because browsers may implement web standards differently. The website should be tested in two browsers.

Semantic HTML includes elements such as article, section, header, nav and footer. A div is an example of a non-semantic element.
